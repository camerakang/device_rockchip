# SS-07 开发任务与联调验收

目标是六路视频、五路声呐、跟焦、三轴云台、mobocon 定位与时间轴完整联调。以下任务划分用于开发排期与验收，当前完成的是设计，软件实现、镜像和硬件指标尚未完成。

## 1 已确定的设计决策

| ID | 决策 | 影响 |
| --- | --- | --- |
| D01 | RK3588 只负责视频、录像、声呐和相关界面 | 不新增 RK 电机代理 |
| D02 | 本地跟焦器/摇轮经 NRF24 控制接收器 | 原无线链路必须保持回归 |
| D03 | PC 经 Control RS485 直达 F/G | 上行不共用 PDMOVIE 下行 |
| D04 | PC 编辑时单次定位并核对实际位置 | 公共库增加定位与遥测能力；不开发高频摇杆流 |
| D05 | 缓存时间轴复用公共 V1.2 | 不另写事务/授时/Run 状态机 |
| D06 | 首选独立 TimeCode 发生器 | 增加硬件、管理旁路和时序验收 |
| D07 | 实际位置、目标、遥控输入分别显示 | 无反馈不能声称到位 |
| D08 | SDK 独立 SS-07 构建产物 | 不覆盖旧 fusion 平台产物 |

软件建议和硬件参数在各详细设计中标明；待确认项不得通过实现默认值悄悄变为产品承诺。

## 7 验收记录与发布包
