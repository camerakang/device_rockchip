# 五路 720p25 验收

2026-10-26 用户确定：以五路 720p25 标准推进项目验收，执行过程中不再要求用户回答问题。五路 USB 的正式工作模式调整为 H.264 1280×720、25/1 fps，按现场三个控制器的 2＋2＋1 接线运行。原五路 1080p25 的带宽失败及此前失败样本保留为历史证据，不再要求五路 USB 达到 1080p25。

该模式调整不删除录像、恢复、网页权限、声呐、只读时码、镜像交付及长期运行要求。缺少实物条件的项目如实保持待验收，不能通过缩小范围、模拟数据或修改数据盘保护条件取得整机通过。

## 验收依据

- 需求与功能编号以 [项目需求](requirements.md) 为准；USB 模式以本文的用户新指令覆盖旧候选值。
- 五路方向采用当前稳定路径，见 `config/board-rk3588.example.json`；现场先核验设备身份、能力、实际协商及是否占用，重启/恢复后重新核对方向。
- 采用交付包内真实 ARM64 C++ 相机、固定版本 MediaMTX、Python 管理服务、生产 systemd 用户和权限。诊断 gst-launch、保存文件回放、QEMU 与合成源均不替代该链路。
- 软件、实机和完整项目分别报告。短时实际出帧不替代 8 小时持续负载；服务运行或心跳存在不替代客户端解码和文件完整性。

## 本轮已核验的结果

- 正式发布工具完成安装、初始化预检、激活和升级，最终板端为 **0.10.2**，事务 `4f136cce-92b1-4a5d-b5e2-ab7b345d2b3f` 为 COMMITTED；版本完整性与软件健康检查通过。候选/运行配置均恢复到现场原修订 `f13878c802a2796a20c0f63556d5e0138033ba5f0c1445f87317d253fb45b2d1`，录像关闭。软件健康通过不代表硬件整体验收。
- 发现并修复两个实际问题：0.10.1 为 MediaMTX 的 Go/Pion 接口枚举补充 `AF_NETLINK`，消除 WHEP 400；0.10.2 修复维护日志空查询返回 422，缺省读取 access 日志，畸形/重复参数仍拒绝。240 项测试分别在开发机和 ARM64 Python 3.8.10/QEMU 通过。
- 真实生产 systemd 用户、原生相机、MediaMTX、Caddy 与 LAN 页面完成五路 1280×720 解码、主画面切换和退出清理。最终 0.10.2 的 12 秒测量直接读取 WebRTC `framesDecoded`，五路均约 24.992fps，测量段呈现丢帧增量均 0。该结论仅覆盖这段短测；较早短测及长期尝试中的呈现丢帧、V4L2 丢帧和无效 NAL 告警均保留。
- API 重启后五个相机 supervisor/native 进程与媒体服务身份保持，旧登录失效。五路分别停止/恢复服务、解绑/重新绑定真实 UVC 接口时，其他通道持续解码，稳定 USB 物理路径保持。UVC 驱动重新枚举不是电气拔线、方向安装或冷启动验收。
- 真实维护页面验证保存与运行配置分离、过期修订返回 409、仅重启 API 的选择性应用、重新登录及原配置还原。三角色通过实际 HTTPS 验证读写权限、CSRF 和退出失效；测试后按 CAS 恢复原账户集合。0.10.1 的恢复/配置证据继续保留，0.10.2 的相关 26 个组件逐字节一致性另有记录。

## 长期观测与待验收项

长期观测使用独立 systemd 任务，必须同时核对 MainPID、ActiveState、新鲜进度和真实解码计数。第一轮因采样时间顺序与窗口前告警计数的脚本问题停止；第二轮保留实际丢帧，因相机主进程与插件扫描器共用日志文件改进记录方式后停止。两轮均不计作八小时完成。第三轮位于 `soak-03/`，GStreamer 日志按通道和进程 PID 隔离，保留窗口前全文及窗口中新告警；每通道日志总量有上限，退出后清理临时诊断环境。

观测保留浏览器每路 `framesDecoded`、呈现丢帧、RTP 丢包、连接及 5 秒窗口帧率，以及 RK 的实际采集/发布快照、进程 CPU/RSS、内存、温度、磁盘和告警。23～27fps 的五秒窗口检查用于发现偏差，不更改 25fps 的协商目标。偏差和启动重试不得删除、忽略或据此声称零丢帧。以最终结果文件确认时长和结果；启动成功不等于长期通过。

当前只有系统 eMMC、无录像数据盘；SE2017 仍缺有效 SDI 输入；真实厂家声呐协议/驱动和实物、时码适配器绑定及其余参数缺失。实盘六路录制/回放/故障、物理零 TX、声学互扰、端到端延迟、冷启动/掉电、新 IMG 启动和外部运动系统独立性均不能写成通过。即使第三轮五路持续监看完成，也不能单独完成 R07 或整机验收。
