# SS-07 两软件开发与验收

本计划仅对应RK3588系统与云台接收器软件。跟焦为既有系统，mobocon为外部PC端，供mobocon/UE及RK只读接入的RS485时码器与公共V2.2 UDP接入为外部依赖；不把它们列为本次新增软件交付。

## 1 RK3588工作包

| ID | 工作 | 依赖与交付 |
| --- | --- | --- |
| R01 | 设备探测与稳定绑定 | 相机/Hub/声呐资料；模式、端口与身份表 |
| R02 | 单通道采集和六路发布 | R01；五USB直通与SE2017接入、重连 |
| R03 | 视频网页/API | R02；主辅画面、年龄、告警、配置 |
| R04 | 录像与索引 | R02；分段、回放、保留/锁定、缺盘保护 |
| R05 | 五声呐驱动与服务 | 厂家协议；公平采集、坏帧/离线处理 |
| R05T | RK时码服务与记录关联 | 独立时码接口；0x12验证、映射/epoch/质量、侧录索引与网页状态 |
| R06 | SDK完整镜像 | R02–R05T；独立启动组件/内核/rootfs/应用构建记录和IMG |
| R07 | RK独立验收 | 六路满载、声呐、时码记录、存储、冷启动/更新/恢复 |

## 2 云台接收器工作包

| ID | 工作 | 依赖与交付 |
| --- | --- | --- |
| G01 | 板级接口和外设原型 | 实际原理图；Ethernet/PHY、DHCP/组播、CAN资源核验，取消TimeCode接口 |
| G02 | 摇轮接收与映射 | 发送端载荷；校验/新鲜度/轴语义 |
| G03 | CyberGear单轴驱动 | G01；身份、反馈、模式、受限运动/停止 |
| G04 | 三轴与持久标定 | G03；方向、零位、范围、负载与参数 |
| G05 | 来源门控和本地轨迹 | G02/G04；公共DeviceCore唯一输出/交接、每资源TTL/来源租约、驱动限速 |
| G06 | PC定位/遥测接入 | V2.2 UDP WRITE_TARGETS/STATUS；UID/epoch上下文、持续目标刷新、真实反馈/偏差 |
| G07 | V2.2实时播放接入 | mobocon HostTimeline/RealtimeScheduler；设备目标刷新、动作与结束STOP契约 |
| G08 | 云台独立验收 | 单/三轴、定位、摇轮、失联、卡死保护、电源与固件恢复 |

两组任务可独立推进，不要求先完成RK才能开发云台。每个软件拥有自己的源码版本、构建入口、配置schema和验收记录。开发排期在设备及人员确认后给出。

## 3 外部依赖与边界

| 依赖 | 接入前必须满足 | 不纳入本次工作 |
| --- | --- | --- |
| 跟焦系统 | 按现有设计运行，在共存测试中不受影响 | 跟焦固件/反馈/协议重设计 |
| mobocon | 能按发布协议发送定位/时间轴并显示反馈 | PC页面、工程文件和桌面应用开发 |
| device_protocol | V2.2网络实施候选；真实类别/保持/到位规则、SDK版本与摘要锁定 | 在消费者工程私改公共核心 |
| RS485时码器 | 接mobocon/UE及RK只读接口；格式、三主机线束、时间语义和失效处理核验 | 不增加接收器时码输入/捕获或时码器固件交付 |

若外部接口未提供，可先用台架测试主站/模型验证接收器，记录真实缺口；模型通过不等于mobocon/UE时码与播放实物联调完成。

## 4 独立验收与整机共存

| 范围 | 重点 |
| --- | --- |
| RK软件 | 六路同时监看录像8小时、身份不交换、声呐公平更新、时码接收与录像/声呐记录关联、录像回放及满/缺盘、配置/权限、完整镜像与应用恢复 |
| 云台固件 | 单轴到三轴、实际反馈、模式/零位/限位、持续刷新定位/保持/过期/重复请求、来源互斥、实时目标/主机时码fallback/Control失联及正常结束处理、CAN与固件故障保护 |
| 整机共存 | RK满载时验证共享网络Control抖动/丢包与失联停车；RK进程重启不改云台来源；云台启动/制动不致RK掉电；既有跟焦继续按原设计运行 |

视频延迟、声呐周期、机械容差/稳定时间、停止时间和同步预算分别按两份设计与公共协议冻结；不以日志事件代替真实帧/电气/机械测量。测试记录包含test_id、设备/线束、版本、输入、期望、实测、判定与原始证据。

## 5 发布产物

RK发布包：源码/应用/网页、配置/systemd、完整IMG与SHA256、sources/packages清单、设备安装表、运行和恢复说明、独立验收报告。

云台发布包：独立固件与SHA256、板型/引脚配置、工具链/SDK锁定、真实类别/标定schema、CAN向量/抓包、安装操作和恢复说明、独立验收报告。

整机记录只冻结经过共存验证的两个软件版本组合，并记录外部跟焦/mobocon/发生器版本；不将这些外部系统再次打包为本次新软件项目。

G07按V2.2 UDP实时Control接入，无节目缓存/设备授时/T0。UE策略与PC真实网络时延仍是外部集成条件；G01–G06可独立推进。文档修订不代表这些工作包已实现或验收。
