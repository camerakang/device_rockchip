# V2.2 网络设备类别契约

公共核心以逻辑资源为接口。跟焦、云台、风扇分别发布类别，不按接收器硬件外形归为同一设备。真实类别维护在设备仓库；本库只提供公共模板和明确虚拟夹具。

类别type必须从[公共注册表](DEVICE_TYPES.md)选择，通过SDK的DeviceType常量填入，不自行填写新数值。跟焦接收器发布FOCUS_MOTOR，多路风机板发布FAN；下游多个电机/输出由endpoint/resource描述。新增类型、停用和永久ID规则见注册表。新增正式类型仅分配身份，不代表本库已经实现其实际资源、单位、驱动或安全参数。

## 真实类别必填模板

| 内容 | 必须填写 |
| --- | --- |
| 身份 | 从公共注册表选择type常量；profile_version、firmware、UID来源、boot_id跨重启唯一方法；UID不作为可分配的网络地址 |
| 网络 | 推荐DHCP/子网、控制网卡、UDP47821及239.255.33.21组播TTL=1；所有状态发现、可选mDNS名称、重复IP/UID诊断、endpoint变更后的重新发现与显式建会话 |
| 资源 | endpoint/resource/unit/flags/group；i32 编码、物理单位、量化误差、范围；是否持续输出及实际反馈能力 |
| 驱动 | 最大目标处理频率、驱动刷新最坏间隔；目标如何交付；限速/限加速度、危险耦合校验、批次/组内共同更新要求 |
| 来源 | 支持 REMOTE/MOBOCOM；开机选择；NRF24 配对、合法帧和新鲜序号；来源切换清 FIFO/软件队列流程 |
| 超时 | target 和 lease 的允许范围、实际配置值、周期看门狗执行间隔、最坏检测延迟 |
| 动作 | opcode、参数逐字段布局、单位/范围、占用掩码、参数校验、启动副作用、成功依据、硬超时、取消与失败处理 |
| 安全 | 正常 STOP、ESTOP、失联、目标过期、驱动/动作故障、切换失败的实际电气/机械行为与最坏期限；start_safe 必须按 reason 区分。有物理限位开关的类别写明何时报 LimitTrip（而非 Driver）、开关有效时允许的方向和复位条件 |
| 确认/复位 | safe_confirmed 的真实条件；输出不确定时保持 false；RESET_FAULT 的硬件条件，故障不得因重连清除 |
| 急停 | 软件停止、物理急停有无与电路、断线时保障范围；UDP STOP 不能替代物理急停 |
| 反馈 | 实测位置/速度/传感器来源、最大允许数据年龄、有效判定、到位容差、稳定时间和查询周期；开环只能提供命令目标，不能冒充反馈 |
| 定位/保持 | 编辑定位的移动与确认依据、到位后的持续目标刷新、保持期间驱动约束、退出定位后的安全释放；无反馈时标注命令关键点或人工确认 |
| 接线/验收 | 主控型号、Ethernet/PHY/网络接口与交换机、供电/隔离、私有下游CAN/PDMOVIE/GPIO参数、网络丢包/乱序/拥塞及实测延迟/抖动/停止时间和报告 |

任何安全、硬件或单位缺项都标“未配置”，不得使用虚拟值启用真实驱动。类别版本改变已有字段含义时需变更版本；不能用固件更新悄悄重解释单位。公共事务、CRC、控制来源和状态机不复制到类别驱动。

安全契约必须逐项说明保持、制动、卸力的条件和确认依据，不能把停止发包或驱动 ACK 当成机械安全。Pitch/Roll 等重力负载轴还需明确允许负载、姿态、制动器控制顺序、失电行为及防坠条件。公共库不决定这些机械动作；未验证的轴不得默认以卸力作为 STOP。

反馈有效性由真实适配器负责，过期传感器读数必须失效。公共 STATUS 没有反馈采样时间，CAPS 没有到位容差或稳定时间字段；这些参数必须在类别和应用契约中约定。需要线上传输这些额外信息时应另行设计有版本的扩展，不能擅自改变现有公共字段。

## 本库虚拟夹具

| 类别 | type | 资源 | 虚拟单位/范围 | 动作 |
| --- | --- | --- | --- | --- |
| VIRTUAL_LENS | 8001 | endpoint 1，resource 1/2/3 | 8001 虚拟整数，0～10000，无实测反馈 | opcode 1，空参数，占用全部三资源 |
| VIRTUAL_GIMBAL | 8002 | endpoint 1，resource 1/2 | 8002 虚拟整数，-180000～180000；group 1；声明反馈支持但默认无有效反馈 | opcode 1，空参数，占用两轴 |
| VIRTUAL_FANS | 8003 | endpoint 1～3，各 resource 1～3 | 8003 虚拟整数，0～10000，无实测反馈 | opcode 1，空参数，不占用目标资源 |

都支持两种来源，max_target_hz=100，update_gap_us=10000；target 允许 20000～1000000µs，lease 允许 50000～3000000µs，安全和切换硬期限均 100000µs。示例配置 target=100000、lease=300000；虚拟安全操作清输出，默认立即确认；动作模拟 20000µs 完成，硬期限 500000µs。

虚拟云台 vmax=90000、amax=180000，仅作为能力字段的测试数据。虚拟驱动不模拟机械运动，不据此声称限速曲线或实际到位。真实云台适配必须实现真实机械约束后才能发布对应能力。

夹具编码见[profiles.py](profiles.py)，三份[流程样例](examples/1_walkthrough.json)分别记录请求、回复及 tick 时刻。示例不会输出 PDMOVIE、CAN 或真实 PWM。

## 自动恢复能力

auto_reset_mask:u32默认0，仅允许bit1(SourceTimeout)与bit2(TargetExpired)。声明不代表安全已完成；主控只有safeConfirmed且RESET_FAULT类别条件成立时可清除。Driver、StopTimeout、SwitchTimeout、ActionTimeout、Estop、LocalClock、OutputGap、LimitTrip不允许自动清除。安全操作失败必须覆盖可恢复的软件首因，避免错误清除真实故障。
